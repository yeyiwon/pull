# Active Moru baseline

15 user-approved source GLBs remain in public/moru. The visible model is moru-walk.glb; lossless animation-only derivatives use the same 23-bone skeleton. Original geometry, textures, UVs and materials are unchanged. Desktop source downloads are untouched.

Cherish_Pop_Dance, Look_Around_Dumbfounded and Talk_with_Hands_Open are excluded from the project assets, runtime manifest, action menus and future import script. There are 4 movement, 5 gesture and 6 dance definitions. Space retains the verified raised-hop segment.

React / Actions / Dance menus and keyboard actions share the semantic expression broker. Movement/jump cancel one-shot actions. Local context dialogue uses silence-first cooldowns, recent-line suppression and one active reaction; calm Listening replaces removed ambient gestures. There are no facial morph controls in this asset, and semantic look reactions do not add eye tracking.

Speech uses a pearlescent translucent thought shape, soft appearance/fade and head-projected positioning. Moru model data, camera, bridge placement and audio files are unchanged by this pass. Brain foundation is retained with small action routing adjustments.

Validation: lint, TypeScript, 66 tests and production build; browser action menus, dance effects, movement/jump cancellation and speech display checked. Full iPhone and sustained performance verification remain outstanding. No commit.
